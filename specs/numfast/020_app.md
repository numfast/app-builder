# App Manifest

**full.toml** — описывает приложение.

---

## Поля

| Секция | Обязательное | Описание |
|--------|-------------|----------|
| `[kernel]` | да | Имя приложения |
| `[[extensions]]` | да | Список расширений |
| `[extensions_meta.*]` | нет | Метаданные для расширений |

---

## Пример

```toml
[kernel]
name = "Calc"

[[extensions]]
name = "_main"
path = "src/_main"

[[extensions]]
name = "Math"
path = "src/Math"

[extensions_meta.Math]
precision = "float64"
```

## Inheritance

```toml
extends = "full.toml"

# Исключить расширение
[[extensions]]
name = "Trig"
exclude = true

# Добавить тесты
[tests]
add = { mod = "add", args = [2, 2], expected = "4" }
```

## Тесты

```toml
[tests]
test_name = { mod = "alias_name", args = [arg1, arg2], expected = "string_result" }
test_name = { expr = "2+2", expected = "4" }
```

Запуск: `python -m app_builder test test.toml`
